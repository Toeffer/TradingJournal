# Research

Use this folder for recurring research outputs, candidate lists, and review notes.

Keep filenames date-based so they sort naturally, for example:

```text
2026-06-24-weekly-review.md
```

**Never let two research passes silently overwrite each other.** If
`candidates-<YYYY-MM-DD>.md` already exists when a new research pass runs the
same day (a manual run alongside the scheduled routine, a re-run, etc.), write
to `candidates-<YYYY-MM-DD>-<HHMM>.md` instead — never overwrite the existing
file (see `RESEARCH_BRIEF.md`'s collision check). This happened once already
and destroyed a candidate's supporting detail before it could be logged.
